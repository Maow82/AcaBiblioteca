
# Sistema de Gestión de Biblioteca - AcaBiblioteca

## Descripción del proyecto

AcaBiblioteca es una aplicación de escritorio desarrollada en C# con Windows Forms, conectada a una base de datos SQL Server. Su propósito es facilitar la administración de la información de una biblioteca mediante diferentes módulos de gestión.

## Objetivo

Desarrollar un sistema que permita organizar y administrar los libros, autores, editoriales, usuarios, préstamos y devoluciones de una biblioteca.

## Tecnologías utilizadas

- C#
- Windows Forms
- .NET
- SQL Server
- ADO.NET
- Visual Studio
- Git y GitHub

## Módulos del sistema

- **Libros:** registro, consulta, actualización y eliminación de libros.
- **Autores:** administración de autores.
- **Editoriales:** administración de editoriales.
- **Usuarios:** registro y administración de usuarios.
- **Préstamos:** gestión de préstamos de libros.
- **Devoluciones:** registro de devolución de libros.
- **Consultas:** visualización de información almacenada.

## Base de datos

El sistema utiliza SQL Server para almacenar y administrar la información mediante tablas relacionadas.
